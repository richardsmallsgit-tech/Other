Is this Luau?

No.

It's Lua 5.1 with my own additions. Some functions might look familiar if you've used Roblox executors, but that doesn't mean this is a Roblox executor or supports Luau syntax.

It's just a modified Lua runtime.

Is it finished?

Not really.

I'm still adding stuff, fixing things, and occasionally breaking something that was working five minutes ago.

The main custom implementation is in src/xenlib.c, and test_xen.lua contains tests for the added functionality.

Feel free to mess around with it.
